# DataForge

Browser-based fictional data generators with consistent XLSX and CSV exports.

## Deployment on Cloudflare Pages

- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`
- Node.js: 22

Connect this GitHub repository to Cloudflare Pages and deploy.

## Local

```bash
npm install
npm run dev
npm run build
```

All data is generated in the browser. No API keys required.
